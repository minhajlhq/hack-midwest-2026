### Requirements

* NodeJS version 20.19 or greater


### Development

#### Web application

* Build

```npx nx build web-app```

* Test

```npx nx test web-app```

* Run locally

```npx nx dev web-app```

This runs the app locally on http://localhost:4200/

#### API

* Build

```npx nx build api```

* Test

```npx nx test api```

* Run locally

```npx nx serve api```

This runs the api locally on http://localhost:3000/api
